# 콘텐츠 스튜디오 (Obsidian)

아이디어 노트 하나로 메시지를 찾고, 코르크판에 재료(포스트잇)를 붙여 가며 글의 뼈대를 모으는 플러그인입니다. **0.2.0은 코르크판 중심 첫 버전**입니다.

## 0.2.0에서 되는 것
- 아이디어 목록, 두 시작점(메시지에서 / 경험·글감에서) → 아이디어 폴더에 노트 생성 (`content-studio: idea`)
- 코르크판: 조사 카드·메모 카드, 고정(카드에서 1클릭), 붉은 실 잇기·풀기, 자리 옮기기(`M`+방향키 / 끌어서 놓기), 고치기(`E`), 버리기·보관함 복구, 카드 찾기(`/`)
- **조사하기**: 로컬 Claude Code(`claude`)가 웹에서 글감을 찾아 카드로 붙입니다. 미설치·로그인 안 됨·실패·네트워크 오류 안내가 있습니다.
- 모든 상태는 노트(`## 메시지` / `## 카드` / `## 판 배치`)에 저장되고, 편집기에서 고친 내용은 2초 안에 반영됩니다. 사용자가 쓴 다른 글은 건드리지 않습니다.

## 아직 없는 것
이야기(역추적 대화)·후킹·얼개·초안 단계(단계열에는 보이지만 눌러도 안내만 나옵니다), 중복 id 처리, 읽기 전용 노트 처리.

## 설치 (BRAT)
BRAT → Add beta plugin → `logos1012/obsidian-content-studio` → 버전 `0.2.0`.
조사 기능은 Claude Code가 설치·로그인되어 있어야 합니다. 사용자의 작업 내용이 외부로 가는 경로는 이 호출과 그 웹 검색뿐입니다.

## 개발
`npm install` → `npm run build` (main.js, styles.css 생성) → `npm test`.
`designs/kraken/`은 이 화면의 디자인 시안(HTML)입니다.

## 글꼴
카드·메시지에 Gaegu(SIL OFL 1.1, © The Gaegu Project Authors)의 한글 2350자·영문 서브셋을 `styles.css`에 넣었습니다. 라이선스: `assets/fonts/OFL-Gaegu.txt`.
